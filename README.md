# Agrotech Market Analysis

## Overview

Analysis of agricultural data to identify promising crops and
regions for the application of Spanish agrotech solutions in Mexico.

## Objective

Identify the crops and Mexican states with the most relevant
characteristics for potential agrotech applications.

## Methodology

- Data cleaning and transformation
- Exploratory data analysis
- Statistical analysis
- Clustering
- Data visualization

## Technologies

- R
- dplyr
- purrr
- stringr
- ggplot2
- tidyverse
- cluster
- Tableau
- SAP

## Key Takeaways

- 37% Export Growth:
Total agricultural exports grew from $11.4B to $15.6B between 2020 and 2024.

- Some crops showed negative CAGR, equally important for investment decisions.
  
- Avocado dominates: Highest export value by a wide margin: 
Mexico's undisputed #1 crop.

- Michoacán, Sinaloa, Jalisco, and Veracruz drive most of the export value.

- Some high-volume states produce lower-value crops, a gap with strategic implications.
